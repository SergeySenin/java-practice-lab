# 1. Переменные и поля в Java

## 1.1. Категории переменных

В Java 17 существует **восемь категорий переменных**.
Они различаются местом объявления и способом получения начального значения.

| Категория                              | Как получает начальное значение                       |
|----------------------------------------|-------------------------------------------------------|
| **1. Поля статические** (`static`)     | Автоматически получают значение по умолчанию          |
| **2. Поля экземпляра**  (без `static`) | Автоматически получают значение по умолчанию          |
| **3. Элементы    массивов**            | Автоматически получают значение по умолчанию          |
| **4. Параметры   методов**             | Получают значения, переданные при вызове метода       |
| **5. Параметры   конструкторов**       | Получают значения, переданные при вызове конструктора |
| **6. Параметры   лямбда-выражений**    | Получают значения, переданные при вызове лямбды       |
| **7. Параметры   `catch`**             | Получают объект перехваченного исключения             |
| **8. Локальные переменные**            | Не получают значений по умолчанию: значение           |
|                                        | должно быть присвоено до первого чтения               |

### Значения по умолчанию для полей и элементов массивов

Эти значения автоматически получают **статические поля, поля экземпляра и элементы массивов**
(категории № 1–3). Для локальных переменных и параметров эта таблица не применяется.

| Тип данных         | Значение по умолчанию       |
|--------------------|-----------------------------|
| `byte`             | `0`                         |
| `short`            | `0`                         |
| `int`              | `0`                         |
| `long`             | `0L`                        |
| `float`            | `0.0f`                      |
| `double`           | `0.0d`                      |
| `char`             | `'\u0000'` (нулевой символ) |
| `boolean`          | `false`                     |
| Все ссылочные типы | `null`                      |

К ссылочным типам относятся `String`, `Integer`, `List`, другие классы, интерфейсы и массивы.
Например, для поля `int` значение по умолчанию — `0`, а для поля `Integer` — `null`.

**Это означает**: `null` — отсутствие ссылки на объект, а не пустая строка `""`.
Если впоследствии поле или элемент массива получает другое значение, оно заменяет начальное.

### Что относится к локальным переменным (категория № 8)?

**Общее правило**: локальную переменную можно объявить без значения и присвоить его позднее.
Однако до первого чтения переменная должна получить значение на каждом возможном пути выполнения.
Компилятор проверяет соблюдение этого требования.

В таблице выражение **«Общее правило»** обозначает именно это требование.

| Где объявляются              | Особенность                                    |
|------------------------------|------------------------------------------------|
| Внутри методов               | Общее правило                                  |
| Внутри конструкторов         | Общее правило                                  |
| Внутри лямбда-выражений      | Общее правило; в теле с блоком `{ ... }`       |
| В статических   блоках       | Общее правило; внутри `static { ... }`         |
| В нестатических блоках       | Общее правило; внутри `{ ... }` класса         |
| В обычных блоках `{ ... }`   | Общее правило                                  |
| В `if` / `else`              | Общее правило; внутри блоков ветвей            |
| В `switch`                   | Общее правило; с учётом выбранной ветви        |
| В обычном цикле `for`        | Общее правило; в заголовке или теле цикла      |
| В цикле `for-each`           | Получает очередной элемент при каждой итерации |
| В цикле `while`              | Общее правило; внутри тела цикла               |
| В цикле `do-while`           | Общее правило; внутри тела цикла               |
| В блоке `try`                | Общее правило                                  |
| В блоке `catch`              | Общее правило; не путать с параметром `catch`  |
| В блоке `finally`            | Общее правило                                  |
| В `try-with-resources`       | Новый ресурс получает значение при объявлении  |
| В блоке `synchronized`       | Общее правило                                  |
| При сопоставлении с образцом | Получает значение при успешном сопоставлении   |
| (`pattern matching`)         |                                                |

Уточнения:

* **Категории и типы**.

  Тип переменной не определяет её категорию.
  `String`, `List`, `Set`, `Map`, `record`, `enum`
  и другие типы не образуют новых категорий.
  Категория определяется тем, где и как объявлена переменная.

  Например, `List<String> names` может быть
  полем класса, параметром или локальной переменной.

  **Это означает**: коллекция не является особой разновидностью переменной.
  Правила инициализации зависят от её категории.

* **Поля интерфейсов**.

  Все поля интерфейсов неявно объявлены как `public static final`.
  Каждое такое поле обязательно должно иметь инициализатор при объявлении.

  ```
  interface AppSettings {
      int MAX_USERS = 100;   // ← Неявно public static final

      // int TIMEOUT;        // ← Нельзя: нет инициализатора
  }
  ```

  **Это означает**: значение можно прочитать через `AppSettings.MAX_USERS`,
  но повторно присвоить его полю нельзя.

* **Массивы**.

  Поле            `int[] numbers` без явной инициализации содержит         `null`.
  После создания  `new int[3]`    каждый элемент массива получает значение `0`.
  Переменная типа `int[]`         хранит ссылку на массив, а не сами его элементы.

  ```
  class Example {
      int[] numbers;                             // ← Поле: null
                                                 // int[]   — тип поля: ссылка на массив целых чисел
                                                 // numbers — имя поля.

      void initialize() {
          System.out.println(numbers);           // ← null

          numbers = new int[3];                  // ← Создан массив из 3 элементов
                                                 // new int[3] — выражение создания массива.
                                                 // new        — оператор создания объекта.
                                                 // int        — тип элементов массива.
                                                 // [3]        — количество элементов.

          System.out.println(numbers.length);    // ← 3: длина массива
          System.out.println(numbers[0]);        // ← 0: первый элемент
          System.out.println(numbers[1]);        // ← 0: второй элемент
          System.out.println(numbers[2]);        // ← 0: третий элемент

          numbers[1] = 50;                       // ← Изменён второй элемент
          System.out.println(numbers[1]);        // ← 50

          int[] copy    = numbers;               // ← Копируется ссылка, не массив
                copy[0] = 25;                    // ← Изменяем элемент через copy
          System.out.println(numbers[0]);        // ← 25: тот же массив
      }
  }
  ```

  Здесь  `numbers` и `copy` — две переменные, ссылающиеся на один массив.
  Запись `numbers[1]` обращается к элементу по индексу `1`, а не к самой ссылке.

  **Это означает**: ссылка на массив и его элементы инициализируются отдельно.
  Создание массива автоматически заполняет элементы значениями по умолчанию.
  Копирование ссылки не создаёт второй массив.

* **Обычные и вложенные блоки**.

  Блок `{ ... }` — участок кода, внутри которого могут объявляться локальные переменные.

  В Java существуют внешние и вложенные блоки.
  Например, блок метода может содержать блок `if`, а тот — блок цикла `for`.
  Внешним называют блок, который содержит другой блок; вложенным — блок, расположенный внутри него.

  Рассмотрим метод, который выводит сведения об отчёте:

  ```
  class Report {
      void printReport(boolean showPages) {
          String title = "Отчёт";                           // ← Переменная метода
          System.out.println(title);

          if (showPages) {                                  // ← Блок условия
              int pages = 2;                                // ← Переменная блока if

              for (int page = 1; page <= pages; page++) {
                  System.out.println("Страница " + page);
              }
          }

          // System.out.println(pages);                     // ← Нельзя: вне блока if
          // System.out.println(page);                      // ← Нельзя: вне цикла for
      }
  }
  ```

  При вызове `new Report().printReport(true)` результат будет следующим:

  ```text
  Отчёт
  Страница 1
  Страница 2
  ```

  Разберём расположение переменных:

  1. `showPages` — параметр метода, категория № 4.
  2. `title`     — локальная переменная метода, категория № 8.
  3. `pages`     — локальная переменная внутри `if`, категория № 8.
  4. `page`      — локальная переменная, объявленная в заголовке `for`, категория № 8.

  Переменная `title` доступна после её объявления в методе.
  Переменная `pages` доступна внутри блока `if`,  но не после его завершения.
  Переменная `page`  доступна внутри цикла `for`, но не после него.

  Аналогичные локальные переменные могут объявляться внутри конструкторов,
  `while`, `do-while`, `try`, `catch`, `finally` и других блоков.

  **Это означает**: расположение переменной внутри другого блока
  не создаёт новой категории, но ограничивает область её видимости.
  Все показанные локальные переменные подчиняются общему правилу присваивания.

* **Параметр `catch`**.

  Переменная  в круглых скобках `catch`              относится к категории № 7.
  Переменные, объявленные внутри его тела `{ ... }`, относятся к категории № 8.

  ```
  try {
      Integer.parseInt("abc");
  } catch (NumberFormatException error) {    // ← № 7: параметр catch
      String message = error.getMessage();   // ← № 8: локальная переменная
  }
  ```

  **Это означает**: параметр исключения получает значение автоматически,
  а обычные локальные переменные внутри `catch` подчиняются общему правилу.

* **Цикл `for-each`**.

  Переменная в заголовке получает очередной элемент массива или коллекции
  при каждой итерации. Вручную присваивать очередное значение не требуется.

  ```
  int[] numbers = {10, 20};

  for (int number : numbers) {      // ← Сначала 10, затем 20
      System.out.println(number);   // ← Вывод: 10 и 20
  }
  ```

  **Это означает**: переменная `number` получает значение автоматически
  для каждой итерации, а не сохраняет значение предыдущей.

* **`try-with-resources`**.

  Новый ресурс в `try-with-resources` должен получить значение при объявлении.
  Java автоматически закрывает такой ресурс по завершении работы конструкции.

  ```
  try (var scanner = new java.util.Scanner("Анна")) {
      // ↑ scanner сразу получает созданный объект
      System.out.println(scanner.next());    // ← Вывод: Анна
  }
  ```

  Начиная с Java 9 можно также использовать ранее объявленную переменную,
  если она уже инициализирована и является `final` или *effectively final*.

  *Effectively final* означает, что после первоначального присваивания
  переменная не переназначается, даже если слово `final` отсутствует.

  **Это означает**: для нового ресурса значение требуется сразу.
  Для ранее созданного ресурса действуют дополнительные ограничения
  на возможность повторного присваивания переменной.

* **`pattern matching` — сопоставление с образцом**.

  Иногда переменная объявлена с общим типом `Object`, но фактически
  содержит ссылку на объект конкретного типа, например `String`.

  Чтобы воспользоваться методами `String`, необходимо убедиться,
  что объект действительно является строкой.

  Раньше для этого обычно использовали отдельную проверку и приведение типа:

  ```
  Object value = "Анна";

  if (value instanceof String) {           // ← Проверяем тип
      String text = (String) value;        // ← Приводим Object к String
      System.out.println(text.length());   // ← Вывод: 4
  }
  ```

  Начиная с Java 16 эти действия можно объединить
  с помощью `instanceof` с образцом типа:

  ```
  Object value = "Анна";

  if (value instanceof String text) {      // ← Проверка и получение text
      System.out.println(text.length());   // ← Вывод: 4
  }
  ```

  Разбор выражения `value instanceof String text`:

  1. `value`             — ссылка, объявленная с типом `Object`.
  2. `instanceof String` — проверка, является ли объект строкой.
  3. `text`              — переменная образца типа `String`, получающая ту же ссылку.
  4. Если проверка успешна, внутри `if` можно использовать `text` как `String`.

  Если вместо строки `value` содержит, например, число `10`,
  проверка не пройдёт и тело `if` не выполнится.

  **Это означает**: `pattern matching` позволяет одновременно проверить
  тип объекта и получить переменную этого типа без явного приведения.
  Переменная доступна только там, где успешность проверки гарантирована.

* **`var` — определение типа переменной компилятором**.

  Начиная с Java 10 вместо явного указания типа в поддерживаемых
  локальных объявлениях можно использовать `var`.

  Компилятор определяет тип по выражению справа от `=`.

  ```
  int    count  = 10;
  var    count2 = 10;       // ← Тип int

  String name   = "Анна";
  var    name2  = "Анна";   // ← Тип String
  ```

  `var` не означает, что тип переменной может изменяться.
  После определения он остаётся фиксированным.

  ```
  var count =   10;   // ← Тип     int
      count =   20;   // ← Можно:  int
  //  count = "20";   // ← Нельзя: String вместо int
  ```

  Для обычного локального объявления `var` требует инициализатор.

  ```
  // var number;         // ← Нельзя: нет значения для определения типа
  // var value = null;   // ← Нельзя: тип нельзя определить из null
  ```

  `var` также разрешён в обычном `for`, `for-each`, объявлениях ресурсов
  `try-with-resources` и параметрах лямбда-выражений (с Java 11).

  При этом `var` нельзя использовать для объявления полей класса
  и обычных параметров методов или конструкторов.

  **Это означает**: `var` сокращает запись объявления, но не меняет
  категорию переменной, правила её инициализации или типизацию Java.

* **`final`**.

  Модификатор `final` ограничивает возможность присваивания переменной.
  Он не создаёт новую категорию, но вводит дополнительные правила инициализации.

  ```
  final int limit = 10;   // ← Значение задано
  //        limit = 20;   // ← Нельзя: повторное присваивание
  ```

  **Это означает**: `final` влияет на возможность присваивания,
  но не меняет категорию переменной.

### Что это означает на практике?

**Главное — различать объявление переменной и получение ею значения.**

Для обычной локальной переменной допустимы оба варианта:

```
int value = 10;    // Объявление с присваиванием

int number;        // Объявление без присваивания
    number = 20;   // Присваивание позднее
```

Но чтение переменной до присваивания запрещено:

```
int number;

// System.out.println(number);   // Нельзя: значение ещё не присвоено

number = 20;
System.out.println(number);      // Можно: 20
```

**Итог**: место объявления определяет категорию переменной, а категория —
способ получения начального значения и правила его использования.
Для большинства локальных переменных действует единое правило присваивания
до чтения; специальные конструкции могут предоставлять значение автоматически.
