# Короткие задачи для осмысленного повторения

16 задач для повторения с меньшим количеством однотипных упражнений.
Отобраны за работу с состоянием, данными, связями объектов и особенностями Java.

Важно:

* Это не рейтинг сложности: короткий опыт иногда полезнее большого задания.
* Задачи расположены по сборникам, а не по приоритету.

Рекомендации для повторения:

* Решать без просмотра решения; проверять обычный и граничный случаи.
* №371 можно продолжить после №370; №230 требует сети.
* В №391 дополнительно проверить уведомление после отписки и при пустом списке.
  Это рекомендация для повторения, а не дополнительное требование исходного задания.
