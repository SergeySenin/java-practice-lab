# Инструкции для работы с проектом

Перед созданием или редактированием Markdown-документов в `src/main/java/org/study/javarush/`
или `docs/javarush/` полностью прочитай [памятку JavaRush][r1].
Путь к памятке указан относительно корня репозитория.
На другие учебные направления и общие документы проекта правила этой памятки не распространяются.

Для документов JavaRush применяй общие правила и раздел соответствующего вида документа:
лекции, короткие задачи или расширенные задачи.
Для документов другого назначения в указанных каталогах используй
общие правила, сохраняя их собственную структуру.

Приоритет правил, границы правки текста и технических исправлений определены в памятке.
Соблюдай область и ограничения текущей задачи пользователя.
Памятка — единый источник правил оформления Markdown для JavaRush;
не дублируй их в других проектных инструкциях.
Если памятка недоступна, сообщи об этом до правок и не восстанавливай правила по памяти.
