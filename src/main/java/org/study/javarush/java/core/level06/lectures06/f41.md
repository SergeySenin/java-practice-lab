Явное и неявное приведение типов в Java

## 1. Неявное, или автоматическое, приведение типов

В Java, как и в других языках, переменные имеют строгий тип: если переменная объявлена
как `int`, то она может хранить только целые числа, а если как `double` — числа
с плавающей точкой. Но в реальных программах часто возникает ситуация, когда нужно
переложить значение из одной переменной в другую с другим типом. Например:

* получили из метода `int`, а хотите использовать его как `double` для вычислений
  с дробными числами;
* храните код символа как число `int`, а хотите получить сам символ `char`;
* есть результат вычислений в `double`, а нужен целый результат `int`, например чтобы
  вывести количество целых яблок.

В Java есть два основных способа преобразования типов: **неявное**, или автоматическое,
и **явное**, или ручное.

### Что это такое?

**Неявное приведение** — это ситуация, когда Java сама, без вашего участия, преобразует
значение из одного типа в другой.

Обычно это происходит при преобразовании от более узкого типа к более широкому. Например,
из `int` в `double`, из `char` в `int`, из `float` в `double`.

Аналогия: представьте, что у вас есть стакан воды (`int`) и ведро (`double`). Если перелить
воду из стакана в ведро, ничего не прольётся, всё поместится. Java в таких случаях разрешает
автоматическое преобразование.

### Пример: `int` → `double`

```
int apples = 5;
double applesWeight = apples;      // int автоматически становится double

System.out.println(applesWeight);  // 5.0
```

### Пример: `char` → `int`

Символ `char` в Java связан с числовым кодом Unicode. Поэтому преобразование `char`
в `int` происходит автоматически:

```
char letter = 'A';
int code = letter;         // 'A' превращается в 65, код символа в Unicode

System.out.println(code);  // 65
```

### Таблица неявных преобразований

| Откуда  | Куда можно преобразовать неявно           |
|---------|-------------------------------------------|
| `byte`  | `short`, `int`, `long`, `float`, `double` |
| `short` | `int`, `long`, `float`, `double`          |
| `char`  | `int`, `long`, `float`, `double`          |
| `int`   | `long`, `float`, `double`                 |
| `long`  | `float`, `double`                         |
| `float` | `double`                                  |

Важно: неявное преобразование работает только в сторону расширения типа. При этом для
переходов вроде `int` → `float` или `long` → `double` возможна потеря части точности,
но само преобразование Java всё равно разрешает автоматически.

## 2. Явное, или ручное, приведение типов: type casting

**Явное приведение** требуется, когда вы хотите преобразовать значение из более широкого типа
в более узкий или между типами, которые Java не преобразует автоматически. В этом случае
Java требует, чтобы вы явно указали: вы осознаёте возможную потерю данных.

Аналогия: вы пытаетесь перелить воду из ведра (`double`) в стакан (`int`). Часть воды может
пролиться, и Java требует, чтобы вы явно сказали: «Да, я понимаю, что часть данных может
потеряться».

### Синтаксис

```
тип_назначения переменная = (тип_назначения) выражение;
```

Синтаксис явного приведения, или cast

### Пример: `double` → `int`

```
double price = 12.99;
int roundedPrice = (int) price;    // Дробная часть просто отбрасывается

System.out.println(roundedPrice);  // 12
```

Внимание: округления не происходит. Всё после точки просто отбрасывается. Для округления
используйте `Math.round()`.

### Пример: `int` → `char`

```
int code = 66;
char letter = (char) code;   // 66 — это символ 'B'

System.out.println(letter);  // B
```

### Пример: `double` → `float`

```
double d = 3.1415926535;
float f = (float) d;    // Часть точности теряется

System.out.println(f);  // 3.1415927
```

## 3. Преобразование между числами и символами: `char` и числа

### Почему это возможно?

В Java символы `char` связаны с числовыми кодами Unicode. Поэтому их можно преобразовывать
в `int` и обратно.

### Пример: `char` → `int`

```
char ch = 'Ж';
int code = ch;

System.out.println(code); // 1046
```

### Пример: `int` → `char`

```
int code = 8364;
char symbol = (char) code;

System.out.println(symbol); // €
```

Важно: тип `char` занимает 16 бит и хранит значение от 0 до 65 535. Если привести к `char`
слишком большое число, результат может оказаться неожиданным символом.

### Практика: выводим алфавит

```
for (int i = 65; i < 65 + 26; i++) {
    System.out.print((char) i + " ");
}
```

Вывод:

```text
A B C D ... Z
```

## 4. Преобразование между целыми и вещественными числами

### `int` → `double`: неявно

```
int count = 10;
double avg = count;       // Неявное расширение

System.out.println(avg);  // 10.0
```

### `double` → `int`: явно

```
double score = 8.75;
int rounded = (int) score;

System.out.println(rounded); // 8
```

### Как округлить по правилам математики?

Если нужно не просто отбросить дробную часть, а округлить число до ближайшего целого,
используйте `Math.round()`:

```
double price = 8.75;
int rounded = (int) Math.round(price);

System.out.println(rounded); // 9
```

## 5. Что происходит при сужении типа: потеря данных

### Пример: `int` → `byte`

```
int big = 300;
byte small = (byte) big;

System.out.println(small); // 44
```

Почему 44? Потому что `byte` хранит значения от -128 до 127. При приведении `int` к `byte`
старшие биты отбрасываются, и остаются только младшие 8 бит. Для числа 300 это даёт значение
44.

### Пример: `double` → `int`

```
double d = 1e20;
int i = (int) d;

System.out.println(i); // 2147483647
```

Большое число не помещается в диапазон `int`, поэтому результат приводится к ближайшей
границе диапазона. Для слишком большого положительного значения это `Integer.MAX_VALUE`,
то есть `2147483647`.

## 6. Преобразование при вычислениях: смешанные типы

### Пример: `int + double`

```
int a = 3;
double b = 2.5;
double result = a + b;       // int автоматически станет double

System.out.println(result);  // 5.5
```

### Пример: `char + int`

```
char ch = 'A';                     // 65
int offset = 2;
char next = (char) (ch + offset);  // char автоматически станет int

System.out.println(next);          // C
```

## 7. Преобразование между числами и строками

Хотя это не совсем приведение типов, часто возникает задача преобразовать число в строку
и обратно.

### `int` → `String`

```
int x = 123;
String s = Integer.toString(x);

// Или просто:
String s2 = "" + x;
```

### `String` → `int`

```
String s = "456";
int x = Integer.parseInt(s);
```

## 8. Типичные ошибки и нюансы

### Потеря дробной части при `double` → `int`

Очень часто новички думают, что `(int) 3.99` даст 4. На самом деле результат — 3, потому что
дробная часть просто отбрасывается. Для правильного округления используйте `Math.round()`.

### Неявное сужение не работает

Нельзя просто так написать:

```
int x = 300;
byte b = x; // Ошибка компиляции
```

Нужно явно указать приведение:

```
byte b = (byte) x;
```

Но будьте готовы к странным результатам, если число выходит за диапазон `byte`.

### Преобразование между несовместимыми типами

Нельзя написать так:

```
int x = (int) "123"; // Ошибка
```

Строку в число нужно преобразовывать через `Integer.parseInt()`.

### Проблемы с `char` и `int`

Преобразование `int` в `char` работает формально для любого `int`, но если число выходит
за диапазон `char` или указывает на служебную область Unicode, результат может оказаться
неожиданным символом.

### Смешанные типы в выражениях

Если выражение содержит `int` и `double`, результат будет `double`. Это может неожиданно
повлиять на логику программы, если вы ожидаете целое число.

### Округление — это не приведение типа

`(int) x` — это не округление, а простое отбрасывание дробной части. Для округления
используйте `Math.round()`.
