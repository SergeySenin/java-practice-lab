Лайфхаки IDEA для Java

## 1. Автодополнение (`Tab`)

IntelliJ IDEA — это очень умная среда разработки. Некоторые считают её не просто отличной IDE
для разработки на Java, а лучшей IDE в мире вообще. Что, в принципе, недалеко от истины.

Например, у IntelliJ IDEA есть такая великолепная вещь, как **автодополнение**. IDEA разбирает и
анализирует все файлы вашего проекта (включая библиотеки JDK 25) и понимает, какие у вас есть
классы, методы и переменные.

Вы просто начинаете писать слово, а она тут же предлагает подсказки. Одна из самых важных клавиш
— это клавиша табуляции **`Tab`**.

Например, вы хотите использовать динамический массив `ArrayList`. Вам достаточно написать `Arr`,
выбрать предложенный класс `ArrayList` и нажать `Tab`: IDEA допишет название класса полностью.

Если вы после имени объекта **поставили точку**, IDEA предложит список методов и полей,
доступных для этого объекта. Это очень удобно, чтобы не запоминать все методы наизусть.

Например, вы создали переменную с текстом. Вы не обязаны помнить, как называется метод для
перевода текста в верхний регистр. Просто напишите имя переменной и поставьте точку:

Важно! Сначала пишем имя переменной `text`, и только потом ставим точку. В выпадающем списке вы
увидите доступные методы.

### CamelHumps

Допустим, вы хотите написать имя длинного класса, например **`InputStreamReader`**. IntelliJ
IDEA позволяет экономить время: вы можете набрать только заглавные буквы — `ISR`
(`InputStreamReader`) и нажать **`Tab`**. IDEA преобразует эту аббревиатуру в
полное имя класса. Почти магия.

## 2. Live Templates

В IntelliJ IDEA есть множество заготовок кода, которые называются **Live Templates**. Вот самые
популярные для Java-разработчика:

### Метод `main` — `psvm`

Написать `public static void main(String[] args)` вручную — это долго и скучно.

Просто напишите четыре буквы **`psvm`** и нажмите **`Tab`**. IDEA заменит это на:

```
public static void main(String[] args) {

}
```

Запомнить легко: **p**ublic **s**tatic **v**oid **m**ain.

### Вывод на экран — `sout`

Также есть способ быстро написать `System.out.println();`.

Напишите четыре буквы **`sout`** и нажмите **`Tab`**.

Запомнить тоже просто: **s**ystem.**out**.println.

### Вывод переменной — `soutv`

Очень полезный шаблон. Если у вас есть переменная и вы хотите вывести её значение в консоль:

```
var age = 25;
// Напишите soutv и нажмите Tab:
System.out.println("age = " + age);
```

### Цикл — `fori`

Быстро написать классический цикл с индексом можно с помощью команды **`fori`** + **`Tab`**.
IDEA создаст каркас:

```
for (int i = 0; i < ; i++) {
}
```

### Перебор списка — `iter`

Если у вас есть список или массив, используйте **`iter`** + **`Tab`**. IDEA создаст цикл `for-each`:

```
for (String arg : args) {

}
```

### Заметка на будущее — `TODO`

Оставляет специальный комментарий, который подсвечивается в IDEA и попадает в список задач
(вкладка TODO внизу экрана):

```
// TODO: реализовать этот метод позже
```

### Критическая пометка — `FIXME`

Аналог `TODO`, но используется для мест, где код работает неправильно или требует срочного
исправления. IDEA может выделять такие пометки отдельно в зависимости от настроек:

```
// FIXME: здесь возникает ошибка, нужно исправить!
```

Пометки `TODO` и `FIXME` — это комментарии, распознаваемые средой разработки; сами по себе они
не являются обязательными шаблонами Live Templates.

## 3. Postfix Completion

В Java 25 мы часто используем ключевое слово `var`, и Postfix Completion помогает писать код
слева направо, не возвращаясь в начало строки.

Вы пишете выражение, ставите точку и выбираете шаблон:

* **`.var`**  — создаёт переменную, автоматически подставляя тип или `var`.
* **`.sout`** — оборачивает выражение в `System.out.println(...)`.
* **`.not`**  — инвертирует булево выражение (ставит `!`).
* **`.for`**  — создаёт цикл по коллекции.

Примеры:

| Вы пишете                    | После `Tab` получаете                   |
|------------------------------|-----------------------------------------|
| `"Hello".sout`               | `System.out.println("Hello");`          |
| `new Scanner(System.in).var` | `var scanner = new Scanner(System.in);` |
| `isValid.not`                | `!isValid`                              |

## 4. Оборачивание

Иногда нужно поместить уже написанный код внутрь условия `if`, цикла или блока обработки ошибок
`try-catch`.

1. Выделите строки кода.
2. Нажмите **`Ctrl+Alt+T`** (Windows/Linux) или **`Cmd+Opt+T`** (macOS).
3. Выберите нужную конструкцию из списка (`if`, `while`, `try/catch` и др.).

## 5. Безопасное переименование: `Shift+F6`

Никогда не переименовывайте переменные, методы или классы простым удалением текста! Если
переменная используется в 10 местах, вам придётся искать их вручную.

Используйте **Rename Refactoring**:

1. Поставьте курсор на имя переменной.
2. Нажмите **`Shift+F6`**.
3. Введите новое имя и нажмите `Enter`.

IntelliJ IDEA сама найдёт все использования и аккуратно их переименует.

## 6. Поиск везде: `Shift` + `Shift`

Если вы потеряли файл или забыли, где находится настройка в меню, — нажмите клавишу
**`Shift` два раза подряд**.

Откроется окно **Search Everywhere**. Начните писать имя класса или настройки
(например, `Font size`), и IDEA мгновенно это найдёт.

## 7. Local History

Представьте: вы удалили кусок кода, нажали «Сохранить», закрыли файл... А потом поняли, что
удалили лишнее. `Ctrl+Z` уже не поможет.

Вас спасёт **Local History**. IDEA сохраняет локальную историю изменений кода, которую можно
просмотреть и использовать для восстановления прежних версий.

1. Нажмите правой кнопкой мыши в редакторе кода.
2. Выберите **Local History → Show History**.
3. Найдите нужную версию слева и нажмите кнопку возврата **Revert**.

## 8. Стиль кода

Очень часто в результате копирования форматирование кода нарушается: кривые отступы, лишние
пробелы. В Java принят строгий стиль оформления.

Чтобы привести код в порядок, нажмите **`Ctrl+Alt+L`**.

Пример:

Было:

```
public class Main {
   public static void main(String[] args) {
System.out.println("Hello World!");
   if(2<3){
System.out.println("Oops"); }

for(int i=0;i<10;i++){
System.out.println(i);
    }
   }
}
```

Стало:

```
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World!");
        if (2 < 3) {
            System.out.println("Oops");
        }

        for (int i = 0; i < 10; i++) {
            System.out.println(i);
        }
    }
}
```

Настройки стиля можно найти в **Settings → Editor → Code Style**.
