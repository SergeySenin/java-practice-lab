Задание 06. Лаборатория анализа климатических данных (Climate Data Laboratory)

Вы разрабатываете консольную программу для научной метеостанции.

Программа должна хранить технические характеристики станции в разных числовых типах, принимать
климатические измерения, выполнять вычисления с дробными числами, демонстрировать преобразование
типов, проверять точность калибровки и диагностировать необычные числовые результаты.

Основная часть программы моделирует нормальную работу станции.

В конце выполняется отдельный блок диагностики (diagnostics), предназначенный для исследования
особенностей числовых типов Java.

## 1. Структура программы

Создайте класс «решение» (`Solution`).

В классе создайте главный метод программы (`main`).

Подключите:

* класс «сканер» (`Scanner`) из пакета `java.util`;
* класс «десятичный формат» (`DecimalFormat`) из пакета `java.text`.

Создайте объект «консоль» (`console`) типа `Scanner`, связанный со стандартным потоком ввода
(`System.in`).

## 2. Этап 1. Технические характеристики станции

### Количество измерений текущей серии

Переменная «количество измерений» (`measurementCount`) типа «целое число» (`int`):

### Общее количество измерений за всё время

Переменная «общее количество измерений» (`totalMeasurements`) типа «длинное целое число» (`long`):

`12_500_000_000`

При записи литерала:

* используйте разделители разрядов (`_`);
* используйте суффикс типа `long` (`L`).

### Точность старого датчика

Переменная «точность старого датчика» (`legacySensorAccuracy`) типа `float`:

`98.5`

При записи литерала используйте суффикс типа `float` (`F`).

### Поправочный коэффициент

Создайте переменную «поправочный коэффициент» (`calibrationFactor`) типа `double`.

Присвойте ей значение переменной `legacySensorAccuracy`.

Преобразование должно произойти **неявно** (implicit conversion) из `float` в `double`.


## 7. Этап 6. Отбрасывание дробной части

Это преобразование должно **отбросить дробную часть**, а не округлить число.

Для основного теста:

## 8. Этап 7. Округление до ближайшего целого

Используйте метод:

`Math.round()`

для округления `averageTemperature` до ближайшего целого.

Сохраните результат в переменной «округлённая средняя температура» (`roundedTemperature`) типа
`long`.

Для основного теста:


Обратите внимание на различие:


Первое действие отбрасывает дробную часть.

Второе выполняет математическое округление.

## 13. Этап 12. Проверка точности калибровки

Создайте:

* «фактический результат калибровки» (`actualCalibration`) типа `double`;
* «ожидаемый результат калибровки» (`expectedCalibration`) типа `double`;
* «допуск» (`epsilon`) типа `double`.

Присвойте:

```
actualCalibration = 0.1 + 0.2
expectedCalibration = 0.3
epsilon = 0.000001
```

Сначала создайте переменную:

«точное сравнение» (`exactCalibrationMatch`) типа `boolean`.

Сохраните в неё результат:

```
actualCalibration == expectedCalibration
```

Для этих значений ожидается:

```text
false
```

После этого создайте переменную:

«разница калибровки» (`calibrationDifference`) типа `double`.

Вычислите абсолютную разницу с помощью:

`Math.abs()`

Создайте переменную:

«калибровка находится в допустимых пределах» (`calibrationWithinTolerance`) типа `boolean`.

Она должна быть `true`, если:

```
calibrationDifference < epsilon
```

Для тестовых данных:

```text
exactCalibrationMatch → false
calibrationWithinTolerance → true
```

## 25. Что именно должно быть понято после выполнения

### Числовые типы

Вы должны уметь объяснить, почему разные значения могут храниться в:

```
byte
short
int
long
float
double
```

и почему для некоторых литералов нужны суффиксы `L` и `F`.

### `char` и Unicode

Вы должны понимать связь:

```text
char ↔ числовой Unicode-код
```

и различие между неявным:

```text
char → int
```

и явным:

```text
int → char
```

преобразованием.

### `int` и `double`

Вы должны уметь объяснить различие:

```
7 / 2
```

и:

```
(double) 7 / 2
```

### Приведение и округление

Вы должны различать:

```
(int) value
```

и:

```
Math.round(value)
```

Первое преобразует тип с отбрасыванием дробной части.

Второе округляет число.

### Округление и форматирование

Вы должны различать:

```
Math.round(...)
```

и:

```
String.format(...)
DecimalFormat.format(...)
```

Округление может изменить числовое значение, сохранённое для дальнейших вычислений.

Форматирование создаёт текстовое представление значения.

### `double` и точность

Вы должны понимать, почему:

```
0.1 + 0.2 == 0.3
```

может дать `false`, и почему вычисленные `double` часто сравниваются через:

```
Math.abs(a - b) < epsilon
```

### Специальные значения

Вы должны уметь распознавать:

```
Infinity
NaN
```

методами:

```
Double.isInfinite()
Double.isNaN()
```

### Сужение типов

Вы должны понимать, что явный `cast` разрешает выполнить потенциально опасное преобразование, но не
гарантирует сохранение исходного значения.

## 26. Критерии выполнения

Задание выполнено правильно, если:

1. программа компилируется и запускается;
2. используются все требуемые примитивные числовые типы;

14. `Math.round()` используется отдельно от приведения типа;
15. `Math.floor()`, `Math.ceil()` и `Math.rint()` используются для одного исходного значения;
16. округление до двух знаков сохраняется как числовое значение типа `double`;
17. `String.format()` используется только для представления значения;
18. `DecimalFormat` используется для отдельного форматирования большого числа;
19. прямое сравнение `0.1 + 0.2` и `0.3` демонстрирует проблему точности;
20. основная проверка равенства дробных вычислений выполняется через `Math.abs()` и `epsilon`;
21. бесконечность обнаруживается через `Double.isInfinite()`;
22. `NaN` обнаруживается через `Double.isNaN()`;
23. выполняется явное сужение `int → byte`;
24. результат сужения не исправляется вручную;
25. вы можете объяснить различия между преобразованием типа, математическим округлением и
    форматированием;
26. основной и дополнительные тесты дают ожидаемое поведение.
