Задание 02. Бронирование железнодорожного билета

Вы разрабатываете консольную программу для оформления железнодорожного билета.
Пользователь вводит данные пассажира и поездки.
Программа обрабатывает их, регистрирует продажу одного билета,
рассчитывает продолжительность поездки и формирует электронный билет.

Задание закрепляет консольный ввод, обработку строк, преобразование типов
и формирование текстового отчёта.

Используйте Java 17 или Java 21. Сторонние библиотеки не требуются.

## 1. Структура программы

В файле `Solution.java` создайте класс «решение» (`Solution`) и главный метод программы (`main`):

```
public static void main(String[] args)
```

Параметр «аргументы командной строки» (`args`) имеет тип `String[]`.
В этом задании он не используется.
Все действия ниже выполняйте внутри `main`, используя указанные английские имена переменных.

Подключите класс «сканер» (`Scanner`) из пакета `java.util`. Оператором создания объекта (`new`)
создайте «консоль» (`console`) типа `Scanner`, связанную со стандартным потоком ввода (`System.in`).

## 2. Ввод данных

Сначала методом «считать строку» (`nextLine()`) последовательно получите
шесть значений типа «строка» (`String`):

1. «имя пассажира» (`passengerNameInput`);
2. «электронная почта» (`emailInput`);
3. «город отправления» (`departureCityInput`);
4. «город назначения» (`arrivalCityInput`);
5. «стоимость билета в виде текста» (`ticketPriceText`);
6. «продолжительность поездки в минутах в виде текста» (`travelMinutesText`).

На этом этапе `ticketPriceText` и `travelMinutesText` должны оставаться строками,
хотя содержат цифры.

Затем последовательно считайте:

* «количество свободных мест» (`availableSeatCount`) типа «целое число» (`int`) методом `nextInt()`;
* «количество уже проданных билетов» (`soldTicketCount`) типа `int` методом `nextInt()`;
* «расстояние маршрута в километрах» (`routeDistanceKilometers`)
  типа «вещественное число двойной точности» (`double`) методом `nextDouble()`.

`nextDouble()` учитывает текущую локаль: в основном тесте расстояние записано как `179,6`.
Если ваша локаль ожидает десятичную точку, введите `179.6`. Это то же числовое значение.

Непосредственно в коде создайте
«номер вагона» (`carriageNumber`) типа «байт» (`byte`) со значением `7`.

## 3. Обработка текстовых данных

### Имя пассажира

Создайте «имя пассажира» (`passengerName`) типа `String`:
удалите пробелы по краям `passengerNameInput` методом «удалить пробелы по краям» (`trim()`).

В переменную «длина имени пассажира» (`passengerNameLength`) типа `int` сохраните количество
символов очищенного имени `passengerName`, полученное методом «длина строки» (`length()`).

### Электронная почта

Создайте «электронную почту» (`email`) типа `String`: сначала обработайте `emailInput`
методом `trim()`, затем преобразуйте буквы в нижний регистр методом `toLowerCase()`.
Исходную переменную `emailInput` изменять не требуется.

### Маршрут

Создайте две переменные типа `String`:

* «город отправления» (`departureCity`) — результат `trim()` для `departureCityInput`;
* «город назначения» (`arrivalCity`)    — результат `trim()` для `arrivalCityInput`.

Создайте «название маршрута» (`routeName`) типа `String`, соединив
очищенные названия городов через дефис с пробелами: `Helsinki - Tampere` для основного теста.

Создайте «отображаемое название маршрута» (`routeDisplayName`) типа `String` и сначала присвойте
ей значение `routeName`. Затем преобразуйте **только** `routeDisplayName` в верхний регистр
методом `toUpperCase()`. Исходное `routeName` должно сохранить обычный регистр.

## 4. Преобразование строк в числа

Методом `Integer.parseInt()` преобразуйте:

* `ticketPriceText` в «стоимость билета» (`ticketPrice`) типа `int`;
* `travelMinutesText` в «продолжительность поездки в минутах» (`totalTravelMinutes`) типа `int`.

Дальнейшую арифметику выполняйте с полученными числами.

## 5. Расчёт продолжительности поездки

Одной сокращённой записью объявите две переменные типа `int`:

* «полные часы поездки» (`travelHours`);
* «оставшиеся минуты поездки» (`remainingTravelMinutes`).

Полные часы вычислите целочисленным делением `totalTravelMinutes` на `60` оператором `/`.
Оставшиеся минуты получите как остаток от деления `totalTravelMinutes` на `60` оператором `%`.
Для `187` минут должны получиться `3` часа и `7` минут.

## 6. Регистрация продажи билета

При регистрации продажи одного билета:

* увеличьте «количество проданных билетов» (`soldTicketCount`) на единицу
  оператором «инкремент» (`++`);
* уменьшите «количество свободных мест» (`availableSeatCount`) на единицу
  оператором «декремент» (`--`).

Для этих двух изменений используйте именно `++` и `--`, а не обычное присваивание через `=`.

## 7. Преобразование числа в строку

Методом `String.valueOf()` преобразуйте числовую стоимость `ticketPrice` в строку.
Сохраните результат в переменную «стоимость билета текстом» (`ticketPriceAsText`) типа `String`
и используйте её при формировании строки с ценой в электронном билете.

## 8. Номер электронного билета

Создайте «номер билета» (`ticketNumber`) типа `int` со значением `1000`.
После регистрации продажи увеличьте его на единицу оператором `++`.

Создайте «префикс кода билета» (`ticketCodePrefix`) типа `String` со значением пустой строки (`""`).
Сформируйте «код билета» (`ticketCode`) типа `String` с помощью конкатенации (`+`): используйте
`ticketCodePrefix`, текст `"TRAIN-"` и значение `ticketNumber`.

Для основного теста код должен быть `TRAIN-1001`. Число `1001` нельзя записывать
внутри строки вручную. Пустой префикс должен участвовать в выражении, не изменяя результат.

## 9. Демонстрационный путь к файлу билета

Создайте «путь к файлу билета» (`ticketFilePath`) типа `String`.
Для основного теста он должен содержать:

```text
C:\Tickets\TRAIN-1001.txt
```

В строковом литерале экранируйте обратные слеши (`\\`), а код билета подставьте из `ticketCode`.

## 10. Формирование электронного билета

Создайте «электронный билет» (`electronicTicket`) типа `String`. Соберите весь текст билета
**одним строковым значением** по образцу ниже, используя конкатенацию (`+`)
и ранее созданные переменные.

Заголовок `"RAILWAY TICKET"` должен включать сами двойные кавычки; экранируйте их через `\"`.
Отступ перед каждой строкой данных создайте табуляцией (`\t`), а переходы между строками —
символом переноса строки (`\n`). Пробелы после подписей задайте внутри строковых литералов,
сохранив подписи и выравнивание из образца.

После обработки данных выведите `electronicTicket` методом
«вывести с переходом на новую строку» (`System.out.println()`).

## 11. Проверка программы

Скомпилируйте и запустите программу. Последовательно введите:

```text
   Sergey Senin   
   SERGEY.EXAMPLE@MAIL.COM   
   Helsinki   
   Tampere   
2450
187
42
158
179,6
```

Первые четыре строки специально содержат пробелы по краям.
Десятичный разделитель вводите с учётом локали, как описано в разделе ввода данных.

Ожидаемый вывод:

```text
"RAILWAY TICKET"
	Code:            TRAIN-1001
	Passenger:       Sergey Senin
	Email:           sergey.example@mail.com
	Name length:     12
	Route:           Helsinki - Tampere
	Route display:   HELSINKI - TAMPERE
	Carriage:        7
	Distance:        179.6 km
	Travel time:     3 h 7 min
	Price:           2450
	Sold tickets:    159
	Available seats: 41
	File:            C:\Tickets\TRAIN-1001.txt
```

Дополнительно проверьте значения, которые не выводятся отдельными полями билета:
`ticketPrice` должен быть равен `2450`, `totalTravelMinutes` — `187`, `ticketNumber` — `1001`.
