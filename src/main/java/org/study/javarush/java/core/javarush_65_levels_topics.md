## Что может потребовать дополнительного изучения именно по Java

- **Продвинутые Generics:** PECS, wildcards, type erasure.
- **Java Memory Model:** volatile, happens-before, атомарность.
- **Внутреннее устройство JVM:** JIT, ClassLoader, устройство памяти.
- **Тонкости многопоточности:** блокировки, конкурентные коллекции, deadlock.
- **Производительность Java:** профилирование, JMH, оптимизация GC.
- Детали стандартной библиотеки Java и особенности её реализации.
