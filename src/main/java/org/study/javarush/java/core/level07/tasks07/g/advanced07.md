Задание 07. Анализатор результатов чемпионата (Championship Results Analyzer)

Программа обрабатывает имена спортсменов, квалификационные баллы, результаты по дисциплинам
и дополнительные попытки, затем формирует отчёт чемпионата.

Задание закрепляет одномерные, двумерные и зубчатые массивы,
циклы `for` и «для каждого» (`for-each`), методы класса `Arrays`.

Используйте Java 17 или Java 21. Сторонние библиотеки не требуются.

## 1. Структура программы

В файле `Solution.java` создайте класс «решение» (`Solution`) и главный метод программы (`main`):

```
public static void main(String[] args)
```

Параметр «аргументы командной строки» (`args`) типа `String[]` здесь не используется.
Все действия выполняйте внутри `main`, используя указанные английские имена.
Импортируйте `java.util.Arrays` и `java.util.Scanner`.
Создайте «консоль» (`console`) типа `Scanner`, связанную с `System.in`.

Имена считывайте методом `nextLine()`, целые баллы — методом `nextInt()`.
Для отдельных частей строки используйте `System.out.print()`, для законченных строк —
`System.out.println()`. Значения подставляйте из переменных конкатенацией (`+`).
Пробелы выравнивания из образцов должны находиться внутри строковых литералов.

Используйте `for`, когда нужен индекс или изменение элемента, и `for-each` для перебора значений.
Счётчики разных циклов могут повторять указанные имена, если объявлены внутри своих циклов.

## 2. Этап 1. Список спортсменов

Создайте «количество спортсменов» (`athleteCount`) типа `int` со значением `4`.
Создайте массив «имена спортсменов» (`athleteNames`) типа `String[]` через `new`
длиной `athleteCount`. Не подставляйте отдельный литерал `4` при создании массива.

Перед вводом имён выполните демонстрацию значений по умолчанию из следующего этапа.

## 3. Этап 2. Значения элементов `String[]` по умолчанию

Создайте «заметки о спортсменах» (`athleteNotes`) типа `String[]` длиной `athleteCount`.
Сразу выведите `athleteNotes[0]`: ожидается `null`.
Присвойте этому элементу `"Team captain"` и выведите его повторно.

Новый массив строк содержит `null` — отсутствие ссылки на объект, а не пустую строку `""`.

Теперь циклом `for` считайте имена из основного теста в `athleteNames`.
Используйте «индекс имени спортсмена» (`athleteNameIndex`) типа `int`:
от `0` до `athleteNames.length - 1`, увеличение через `++`.

После заполнения выведите `Athletes:`, пробел и `athleteNames.length`.
Для основного теста:

```text
Athletes: 4
```

## 4. Этап 3. Результаты квалификации

Создайте «результаты квалификации» (`qualifyingScores`) типа `int[]` через `new`
длиной `athleteCount`. Циклом `for` считайте по одному результату каждого спортсмена.

Используйте «индекс квалификационного результата» (`qualifyingScoreIndex`) типа `int`:
от `0` до `qualifyingScores.length - 1`, увеличение через `++`.
После ввода основных данных массив содержит `[78, 91, 84, 87]`.

## 5. Этап 4. Работа с индексами

Получите первые элементы по индексу `0`, а последние — через длину соответствующего массива
минус один: `athleteNames.length - 1` и `qualifyingScores.length - 1`.
Не записывайте последний индекс литералом `3`.

Выведите имена и баллы в таком порядке и формате:

```text
First athlete: Alice
First score:   78
Last athlete:  Diana
Last score:    87
```

## 6. Этап 5. Сумма результатов через `for-each`

Создайте «сумма квалификационных баллов» (`qualificationSum`) типа `int` со значением `0`.
Циклом `for-each` обойдите `qualifyingScores`, называя очередное значение
«квалификационный балл» (`qualifyingScore`) типа `int`, и прибавьте его к сумме.
Ручной индекс не используйте. Для основного теста сумма равна `340`.

## 7. Этап 6. Средний результат

Создайте «средний результат квалификации» (`qualificationAverage`) типа `double`.
Явно приведите `qualificationSum` к `double` и разделите на `qualifyingScores.length`.
Не заменяйте длину отдельным числом `4`. Для основного теста ожидается `85.0`.

## 8. Этап 7. Минимальный и максимальный результат

Создайте «минимальный результат» (`minimumScore`) и «максимальный результат» (`maximumScore`)
типа `int`. Обоим присвойте первый элемент `qualifyingScores[0]`.

Циклом `for` с «индексом квалификационного результата» (`qualifyingScoreIndex`)
типа `int` от `1` до конца массива сравните остальные элементы с текущими минимумом
и максимумом и обновляйте их при необходимости. Ожидаются `78` и `91`.

Не используйте начальные значения `0`, `100`, `Integer.MIN_VALUE` или `Integer.MAX_VALUE`:
поиск должен начинаться с реального элемента массива.

## 9. Этап 8. Обратный порядок результатов

Циклом `for` выведите значения `qualifyingScores` в обратном порядке.
Используйте «индекс обратного обхода» (`reverseScoreIndex`) типа `int`:
от `qualifyingScores.length - 1` до `0` включительно, уменьшение через `--`.

Разделяйте значения одним пробелом; после последнего значения перейдите на новую строку:

```text
87 84 91 78
```

## 10. Этап 9. Ссылки на один массив

Создайте «рабочие результаты» (`workingScores`) типа `int[]` и присвойте ей
`qualifyingScores`. Новый массив через `new` здесь не создавайте.

Прибавьте `5` к `workingScores[0]`. Выведите сначала `qualifyingScores`, затем
`workingScores` методом `Arrays.toString()`, каждое значение на отдельной строке.
Оба массива должны отображаться как `[83, 91, 84, 87]`.

Сумма, среднее, минимум и максимум из этапов 5–7 сохраняют значения, вычисленные **до бонуса**.
Повторно их не рассчитывайте: далее демонстрируется изменение самого массива.

### Дополнительная проверка 1. Ссылка не является копией

Эту проверку выполняет изменение выше; повторно прибавлять бонус не нужно.
Объясните, почему изменение видно через обе переменные: они содержат ссылки на один объект-массив.

## 11. Этап 10. Настоящая независимая копия

Создайте «копия результатов» (`qualifyingScoresCopy`) типа `int[]` через `Arrays.copyOf()`.
Копируйте текущее содержимое `qualifyingScores`; длина копии — `qualifyingScores.length`.
Прибавьте `10` к `qualifyingScoresCopy[0]`.

Через `Arrays.toString()` выведите сначала `qualifyingScores`, затем `qualifyingScoresCopy`.
Ожидаются `[83, 91, 84, 87]` и `[93, 91, 84, 87]`.

### Дополнительная проверка 2. Независимая копия

Изменение копии выше не должно менять исходный массив.
Объясните отличие присваивания `workingScores = qualifyingScores` от создания независимого
объекта через `Arrays.copyOf()`. Дополнительное повторение этого эксперимента не требуется.

## 12. Этап 11. Сортировка копии результатов

Создайте «отсортированные результаты» (`sortedQualifyingScores`) типа `int[]`.
Методом `Arrays.copyOf()` скопируйте текущее содержимое `qualifyingScores`
с той же длиной и отсортируйте **только копию** через `Arrays.sort()`.

Через `Arrays.toString()` выведите исходный массив и отсортированную копию:

```text
Original scores: [...]
Sorted scores:   [...]
```

`Arrays.sort()` меняет переданный массив, поэтому порядок `qualifyingScores`
должен остаться прежним. Отсортированная копия для основного теста — `[83, 84, 87, 91]`.

## 13. Этап 12. Результаты финалистов

Создайте «результаты финалистов» (`finalistScores`) типа `int[]` через `Arrays.copyOfRange()`.
Из `sortedQualifyingScores` скопируйте два наибольших значения:
начало диапазона — длина минус `2`, конец — длина массива, не включая этот индекс.

Оба индекса рассчитывайте через `sortedQualifyingScores.length`,
не подставляя индексы для массива из четырёх элементов.
Выведите `Finalist scores:`, пробел и массив через `Arrays.toString()`.
Для основного теста финалисты имеют баллы `[87, 91]`.

## 14. Этап 13. Резервная система подсчёта

Создайте «резервные результаты» (`backupQualifyingScores`) типа `int[]`:
независимую копию текущего `qualifyingScores` через `Arrays.copyOf()` с той же длиной.

Создайте «результаты совпадают» (`qualifyingScoresMatchBackup`) типа `boolean`.
Сравните содержимое массивов методом `Arrays.equals()`, сохраните и выведите результат `true`.

Увеличьте `backupQualifyingScores[0]` на `1`.
Повторите сравнение, запишите результат в ту же переменную и выведите `false`.

## 15. Этап 14. Таблица результатов по дисциплинам

Создайте «количество дисциплин» (`disciplineCount`) типа `int` со значением `3`.
Создайте «результаты соревнований» (`competitionScores`) типа `int[][]`
через `new int[athleteNames.length][disciplineCount]`.

Получается прямоугольная таблица: четыре строки спортсменов и три столбца дисциплин.
Число строк должно определяться через `athleteNames.length`.

## 16. Этап 15. Заполнение двумерного массива

Двумя вложенными циклами `for` считайте результаты дисциплин из основного теста.
Используйте счётчики типа `int`:

* «индекс спортсмена» (`athleteIndex`)    — от `0` до `competitionScores.length - 1`;
* «индекс дисциплины» (`disciplineIndex`) — от `0`
  до `competitionScores[athleteIndex].length - 1`.

Оба счётчика увеличивайте через `++`; внутренний начинайте заново для каждой строки.
Порядок обращения к элементу — `competitionScores[athleteIndex][disciplineIndex]`:
сначала спортсмен, затем дисциплина.

Данные вводятся построчно: сначала `80 75 90` для Alice, затем `92 88 95` для Bob,
`85 79 83` для Charlie и `90 91 89` для Diana.

## 17. Этап 16. Вывод таблицы результатов

Используйте вложенные `for` с теми же именами счётчиков `athleteIndex` и `disciplineIndex`.
Во внешнем цикле берите `competitionScores.length`, во внутреннем —
`competitionScores[athleteIndex].length`. Не подставляйте постоянное число `3`.

Выведите имя из `athleteNames[athleteIndex]`, двоеточие и значения его строки:

```text
Alice:   80 75 90
Bob:     92 88 95
Charlie: 85 79 83
Diana:   90 91 89
```

Для выравнивания подписи из имени и двоеточия используйте `String.format()` с `%-8s`:
это поле шириной не менее восьми символов с выравниванием влево.
Перед каждым баллом добавляйте один пробел. Длинные имена не обрезайте.

## 18. Этап 17. Итоговый балл каждого спортсмена

Создайте «итоговые баллы» (`athleteTotalScores`) типа `int[]` длиной `athleteNames.length`.
Внешним `for` с «индексом спортсмена» (`athleteIndex`) типа `int` переберите строки таблицы.

Для каждой строки создайте «сумма баллов спортсмена» (`athleteTotalScore`)
типа `int` со значением `0`. Внутренним `for-each` переберите её значения,
используя «балл за дисциплину» (`disciplineScore`) типа `int`, и накопите сумму.
Запишите её в `athleteTotalScores[athleteIndex]`.

Для основного теста:

```text
Alice   → 245
Bob     → 275
Charlie → 247
Diana   → 270
```

## 19. Этап 18. Лучший спортсмен

Создайте «индекс победителя» (`winnerIndex`) типа `int` со значением `0`.
Циклом `for` с «индексом спортсмена» (`athleteIndex`) типа `int` от `1`
до конца `athleteTotalScores` найдите максимальный итоговый балл.
Если очередной балл строго больше балла текущего победителя, обновите `winnerIndex`.
При равенстве останется первый спортсмен с этим результатом.

Имя получите из `athleteNames[winnerIndex]`, балл — из `athleteTotalScores[winnerIndex]`:

```text
Winner:       Bob
Winner score: 275
```

## 20. Этап 19. Вывод двумерного массива через `Arrays`

Одной диагностической строкой выведите `competitionScores` через `Arrays.deepToString()`:

```text
[[80, 75, 90], [92, 88, 95], [85, 79, 83], [90, 91, 89]]
```

## 21. Этап 20. Глубокое сравнение двумерных массивов

Создайте «резервная таблица результатов» (`backupCompetitionScores`) типа `int[][]`.
Сначала создайте внешний массив длиной `competitionScores.length` без готовых строк.
Циклом `for` со счётчиком `athleteIndex` типа `int` скопируйте каждую строку
`competitionScores` через `Arrays.copyOf()`, используя длину этой строки.

И внешний массив, и его строки должны быть отдельными объектами с теми же числовыми значениями.
Одной копии внешнего массива недостаточно: тогда ссылки на строки останутся общими.

Создайте две переменные типа `boolean` и выведите их значения:

* «обычное сравнение таблиц» (`shallowCompetitionScoresMatch`) —
  `Arrays.equals()` для `competitionScores` и `backupCompetitionScores`, ожидается `false`;
* «глубокое сравнение таблиц» (`deepCompetitionScoresMatch`)   —
  `Arrays.deepEquals()` для тех же массивов, ожидается `true`.

Первый метод сравнивает элементы верхнего уровня — ссылки на строки.
Второй сравнивает числовое содержимое вложенных массивов.

## 22. Этап 21. Дополнительные попытки спортсменов

Создайте «баллы дополнительных попыток» (`extraAttemptScores`) типа `int[][]`.
Внешний массив должен иметь длину `athleteNames.length`.
Для каждой строки создайте отдельный `int[]` с быстрой инициализацией через `{ ... }`:

| Индекс | Спортсмен | Значения      | Длина |
|--------|-----------|---------------|-------|
| `0`    | Alice     | `5, 7`        | `2`   |
| `1`    | Bob       | `4, 6, 8, 10` | `4`   |
| `2`    | Charlie   | `9`           | `1`   |
| `3`    | Diana     | `3, 5, 7`     | `3`   |

В отличие от прямоугольной таблицы, у этого зубчатого массива длины строк различаются.

## 23. Этап 22. Обход зубчатого массива через `for-each`

Создайте «суммарный балл дополнительных попыток» (`totalExtraAttemptScore`)
типа `int` со значением `0`.
Двумя вложенными `for-each` обойдите `extraAttemptScores` без индексов:

* внешняя переменная — «попытки спортсмена» (`athleteAttemptScores`) типа `int[]`;
* внутренняя         — «балл попытки» (`attemptScore`) типа `int`.

Прибавляйте каждый `attemptScore` к сумме. Для заданных строк ожидается `64`.

## 24. Этап 23. Вывод количества попыток

Отдельным циклом `for` с «индексом спортсмена» (`athleteIndex`) типа `int`
переберите `extraAttemptScores`.
Количество попыток получайте через `extraAttemptScores[athleteIndex].length`:

```text
Alice attempts:   2
Bob attempts:     4
Charlie attempts: 1
Diana attempts:   3
```

Соедините имя спортсмена и текст `" attempts:"`, затем отформатируйте эту подпись через
`String.format()` с `%-17s`. После поля выведите один пробел и количество попыток.
Ширина задаёт минимум символов, поэтому длинные имена сохраняются целиком.

## 25. Этап 24. Заполнение массива через `Arrays.fill()`

Создайте «статусы наград» (`awardStatuses`) типа `String[]` длиной `athleteNames.length`.
Методом `Arrays.fill()` заполните все элементы строкой `"PENDING"`.
Выведите массив через `Arrays.toString()`:

```text
[PENDING, PENDING, PENDING, PENDING]
```

Замените `awardStatuses[winnerIndex]` на `"GOLD"` и выведите массив повторно:

```text
[PENDING, GOLD, PENDING, PENDING]
```

## 28. Дополнительная проверка 3. `for` и `for-each`

Сразу после ввода `qualifyingScores`, до вычислений и бонусов, временно обойдите его
циклом `for-each` с переменной «квалификационный балл» (`qualifyingScore`) типа `int`.

не заменяет элемент массива. После эксперимента удалите временный цикл и вывод.

## 29. Дополнительная проверка 4. Границы массива

На примере `qualifyingScores` определите первый индекс `0` и последний
`qualifyingScores.length - 1`. Объясните отличие длины массива от последнего индекса.

Намеренно обращаться к `qualifyingScores[qualifyingScores.length]` не нужно:
достаточно объяснить, почему такой индекс находится за пределами массива.
