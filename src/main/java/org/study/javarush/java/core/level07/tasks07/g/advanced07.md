Задание 07. Анализатор результатов чемпионата (Championship Results Analyzer)

Вы разрабатываете консольную программу для обработки результатов небольшого спортивного чемпионата.

В программе необходимо хранить списки спортсменов, результаты квалификации, таблицу результатов по
дисциплинам и дополнительные попытки.

Основная цель задания — научиться хранить и обрабатывать связанные наборы данных с помощью:

* одномерных массивов (one-dimensional arrays);
* двумерных массивов (two-dimensional arrays);
* зубчатых массивов (jagged arrays);
* цикла `for`;
* цикла «для каждого» (`for-each`);
* методов класса `Arrays`.

## 1. Структура программы

Создайте класс «решение» (`Solution`).

В классе создайте главный метод программы (`main`).

Подключите:

```
java.util.Arrays
java.util.Scanner
```

Создайте объект «консоль» (`console`) типа `Scanner`, связанный со стандартным потоком ввода
(`System.in`).

## 2. Этап 1. Список спортсменов

Создайте переменную «количество спортсменов» (`athleteCount`) типа `int` со значением:

```
4
```

Создайте массив «имена спортсменов» (`athleteNames`) типа:

```
String[]
```

Размер массива должен определяться значением `athleteCount`.

То есть длина массива не должна отдельно записываться литералом `4` при его создании.

С помощью цикла `for` считайте с клавиатуры четыре имени спортсменов и сохраните их в массив по
порядку.

Для основного теста используйте:

```text
Alice
Bob
Charlie
Diana
```

После заполнения выведите:

```text
Athletes: 4
```

Количество должно быть получено через свойство «длина массива» (`length`):

```
athleteNames.length
```

## 3. Этап 2. Значения элементов `String[]` по умолчанию

До ввода имён создайте отдельный массив:

«заметки о спортсменах» (`athleteNotes`) типа `String[]`

размером `athleteCount`.

Сразу после создания массива, до присваивания строк, выведите значение:

```
athleteNotes[0]
```

Ожидаемый результат:

```text
null
```

После этого присвойте:

```
athleteNotes[0] = "Team captain"
```

и повторно выведите этот элемент.

Этот этап должен продемонстрировать, что элементы массива ссылочного типа `String[]` после создания
содержат `null`, а не пустую строку `""`.

## 4. Этап 3. Результаты квалификации

Создайте массив:

«результаты квалификации» (`qualifyingScores`) типа `int[]`

длиной `athleteCount`.

С помощью цикла `for` считайте по одному результату для каждого спортсмена.

Основные тестовые данные:

```text
78
91
84
87
```

После ввода массив должен содержать:

```text
[78, 91, 84, 87]
```

## 5. Этап 4. Работа с индексами

Используя индексы массива, выведите:

```text
First athlete: Alice
First score: 78
Last athlete: Diana
Last score: 87
```

Последний индекс нельзя записывать вручную как `3`.

Определите его через:

```
array.length - 1
```

Для имён используйте длину `athleteNames`, а для результатов — длину `qualifyingScores`.

## 6. Этап 5. Сумма результатов через `for-each`

Создайте переменную:

«сумма квалификационных баллов» (`qualificationSum`) типа `int`

со значением `0`.

С помощью цикла «для каждого» (`for-each`) пройдите по значениям массива `qualifyingScores` и
вычислите сумму.

Внутри этого цикла ручной индекс использовать не требуется.

Для тестовых значений:

```text
qualificationSum → 340
```

## 7. Этап 6. Средний результат

Создайте переменную:

«средний результат квалификации» (`qualificationAverage`) типа `double`.

Рассчитайте:

```text
qualificationSum / количество результатов
```

Чтобы результат был дробным, выполните явное преобразование суммы к типу `double`.

Используйте:

```
qualifyingScores.length
```

а не отдельную переменную с числом `4`.

Для основных данных:

```text
qualificationAverage → 85.0
```

## 8. Этап 7. Минимальный и максимальный результат

Создайте:

* «минимальный результат» (`minimumScore`);
* «максимальный результат» (`maximumScore`).

Обе переменные имеют тип `int`.

Начальные значения возьмите из первого элемента массива:

```
qualifyingScores[0]
```

С помощью цикла `for` найдите минимальное и максимальное значения.

Для основного теста:

```text
minimumScore → 78
maximumScore → 91
```

Не задавайте начальные значения как:

```
0
100
Integer.MIN_VALUE
Integer.MAX_VALUE
```

Цель этого этапа — использовать реальный первый элемент массива как исходную точку поиска.

## 9. Этап 8. Обратный порядок результатов

С помощью цикла `for` выведите массив `qualifyingScores` в обратном порядке.

Для основного теста:

```text
87 84 91 78
```

Начальный индекс должен определяться через:

```
qualifyingScores.length - 1
```

## 10. Этап 9. Ссылки на один массив

Создайте новую переменную-массив:

«рабочие результаты» (`workingScores`).

Присвойте ей:

```
qualifyingScores
```

Новый массив через `new` на этом этапе не создавайте.

После присваивания измените:

```
workingScores[0]
```

прибавив к первому результату `5` бонусных баллов.

После изменения выведите:

```
qualifyingScores
workingScores
```

с помощью:

```
Arrays.toString()
```

Обратите внимание на результат.

Изменение, сделанное через `workingScores`, должно быть видно и через `qualifyingScores`.

На этом этапе обе переменные должны ссылаться на **один и тот же объект-массив**.

## 11. Этап 10. Настоящая независимая копия

Чтобы дальнейший анализ не изменял исходный массив, создайте:

«копия результатов» (`scoresCopy`) типа `int[]`.

Используйте:

```
Arrays.copyOf()
```

Новая длина должна быть равна:

```
qualifyingScores.length
```

После создания копии измените:

```
scoresCopy[0]
```

например, прибавив ещё `10`.

После этого снова выведите:

```
qualifyingScores
scoresCopy
```

Изменение в `scoresCopy` **не должно** изменить `qualifyingScores`.

Вы должны увидеть практическую разницу между:

```
workingScores = qualifyingScores
```

и:

```
Arrays.copyOf(...)
```

## 12. Этап 11. Сортировка копии результатов

Создайте ещё одну независимую копию:

«отсортированные результаты» (`sortedScores`).

Скопируйте в неё текущее содержимое `qualifyingScores` через `Arrays.copyOf()`.

После этого отсортируйте **только копию** методом:

```
Arrays.sort()
```

Выведите:

```text
Original scores: [...]
Sorted scores: [...]
```

через `Arrays.toString()`.

Исходный массив `qualifyingScores` не должен изменить порядок элементов в результате сортировки
`sortedScores`.

Метод `Arrays.sort()` должен применяться именно к копии.

## 13. Этап 12. Результаты финалистов

Из отсортированного массива создайте новый массив:

«результаты финалистов» (`finalistScores`).

Используйте:

```
Arrays.copyOfRange()
```

Скопируйте два наибольших значения из `sortedScores`.

Поскольку массив отсортирован по возрастанию, нужные значения находятся в его конце.

Индексы диапазона рассчитайте через `.length`.

Не записывайте конкретные индексы исходя из того, что спортсменов ровно четыре.

Выведите:

```text
Finalist scores: [...]
```

## 14. Этап 13. Резервная система подсчёта

Создайте независимую копию текущего массива `qualifyingScores`:

«резервные результаты» (`backupScores`).

Используйте `Arrays.copyOf()`.

Создайте переменную:

«результаты совпадают» (`scoresMatch`) типа `boolean`.

Сравните содержимое:

```
qualifyingScores
backupScores
```

методом:

```
Arrays.equals()
```

Ожидается:

```text
scoresMatch → true
```

После этого измените один элемент `backupScores` и повторите сравнение.

Теперь результат должен быть:

```text
false
```

## 15. Этап 14. Таблица результатов по дисциплинам

В чемпионате четыре спортсмена участвуют в трёх дисциплинах.

Создайте двумерный массив:

«результаты соревнований» (`competitionScores`) типа:

```
int[][]
```

Размер:

```text
4 спортсмена × 3 дисциплины
```

Количество строк должно быть связано с:

```
athleteNames.length
```

Количество дисциплин сохраните в переменной:

«количество дисциплин» (`disciplineCount`) типа `int`

со значением:

```
3
```

Создайте массив через:

```
new int[athleteNames.length][disciplineCount]
```

## 16. Этап 15. Заполнение двумерного массива

С помощью двух вложенных циклов `for` считайте все результаты.

Внешний цикл отвечает за спортсменов (`athleteIndex`).

Внутренний — за дисциплины (`disciplineIndex`).

Основные тестовые данные:

```text

92 88 95
85 79 83
90 91 89
```

После заполнения таблица должна соответствовать:

```text
Alice   → 80 75 90
Bob     → 92 88 95
Charlie → 85 79 83
Diana   → 90 91 89
```

При обращении к значению используйте порядок индексов:

```
competitionScores[спортсмен][дисциплина]
```

## 17. Этап 16. Вывод таблицы результатов

Выведите:


## 18. Этап 17. Итоговый балл каждого спортсмена

Создайте одномерный массив:

«итоговые баллы» (`totalScores`) типа `int[]`

длиной `athleteNames.length`.

Для каждого спортсмена:

1. обнулите временную сумму;
2. пройдите по его строке в `competitionScores`;
3. сложите результаты всех дисциплин;
4. сохраните сумму в соответствующий элемент `totalScores`.

Для основного теста:

```text
Alice   → 245
Bob     → 275
Charlie → 247
Diana   → 270
```

## 19. Этап 18. Лучший спортсмен

Найдите индекс спортсмена с максимальным значением в `totalScores`.

«индекс победителя» (`winnerIndex`) типа `int`.

```
totalScores[i]
```

## 20. Этап 19. Вывод двумерного массива через `Arrays`

## 21. Этап 20. Глубокое сравнение двумерных массивов

Создайте второй двумерный массив:

«резервная таблица результатов» (`backupCompetitionScores`).

Инициализируйте его теми же значениями, что находятся в `competitionScores`, но как **отдельный
объект**.

Создайте:

* «обычное сравнение таблиц» (`shallowComparison`);
* «глубокое сравнение таблиц» (`deepComparison`).

Обе переменные имеют тип `boolean`.

Получите:

```
shallowComparison
```

через:

```
Arrays.equals()
```

а:

```
deepComparison
```

через:

```
Arrays.deepEquals()
```

Для двух разных двумерных массивов с одинаковыми числовыми значениями ожидается:

```text
shallowComparison → false
deepComparison → true
```

Цель этапа — увидеть различие между сравнением верхнего уровня массива и сравнением содержимого
вложенных массивов.

## 33. Требования к используемому синтаксису

Решение должно содержать:

* одномерный массив `int[]`;
* одномерный массив `String[]`;
* двумерный массив `int[][]`;
* зубчатый массив `int[][]`;
* создание массива через `new`;
* быструю инициализацию массива через `{ ... }`;
* обращение к элементу по индексу (`array[index]`);
* обращение к элементу двумерного массива (`array[row][column]`);
* свойство длины массива (`length`);
* цикл `for`;
* цикл `for-each`;
* вложенные циклы `for`;
* вложенные циклы `for-each`;
* поиск суммы;
* вычисление среднего;
* поиск минимума;
* поиск максимума;
* обратный обход массива;
* присваивание одной переменной-массива другой;
* класс `Arrays`;
* `Arrays.toString()`;

## 34. Что должно быть понято после выполнения

### Индексы

Вы должны понимать:

```text
первый индекс → 0
последний индекс → array.length - 1
```

и различать:

```text
длину массива
```

и:

```text
последний индекс массива
```

### Массив как объект

Вы должны понимать, что переменная типа:

```
int[]
String[]
int[][]
```

хранит ссылку на объект-массив.

Поэтому:

```
b = a;
```

не создаёт независимую копию массива.

### for и `for-each`

Используйте `for`, если:

* нужен индекс;
* необходимо изменить элемент массива.

Используйте `for-each`, если требуется просто перебрать значения.

### Одномерный и двумерный массив

Вы должны различать:

```
int[]
```

и:

```
int[][]
```

и понимать порядок индексов:

```
matrix[строка][столбец]
```

### Прямоугольный и зубчатый массив

В прямоугольном массиве длины строк совпадают.

В зубчатом массиве:

```
array[0].length
array[1].length
array[2].length
```

могут иметь разные значения.

### `Arrays.sort()`

Метод изменяет переданный массив.

Если исходный порядок требуется сохранить, сначала необходимо создать копию.

### `Arrays.equals()` и `Arrays.deepEquals()`

Для одномерных массивов содержимое сравнивается через:

```
Arrays.equals()
```

Для вложенных массивов:

```
Arrays.deepEquals()
```

### `null`

После создания:

```
String[] values = new String[n];
```

элементы содержат `null`.

`null` означает отсутствие ссылки на объект.

Это не то же самое, что пустая строка:

```
""
```

## 35. Критерии выполнения

Задание выполнено правильно, если:

1. программа компилируется и запускается;
2. имена спортсменов хранятся в `String[]`;
3. квалификационные результаты хранятся в `int[]`;
4. размер массивов определяется через соответствующие переменные или `.length`;
5. последний элемент определяется через `.length - 1`;
6. сумма результатов вычисляется через `for-each`;
7. среднее вычисляется как дробное значение;
8. минимум и максимум определяются на основании элементов массива;
9. массив можно вывести в обратном порядке;
10. присваивание `workingScores = qualifyingScores` не создаёт новый массив;
11. изменение через одну из двух ссылок видно через другую;
12. `Arrays.copyOf()` создаёт независимый объект-массив;
13. изменение копии не изменяет исходный массив;
14. перед сортировкой создаётся отдельная копия;
15. `Arrays.sort()` не уничтожает исходный порядок `qualifyingScores`;
16. диапазон финалистов копируется через `Arrays.copyOfRange()`;
17. содержимое одномерных массивов сравнивается через `Arrays.equals()`;
18. результаты дисциплин хранятся в `int[][]`;
19. таблица заполняется вложенными циклами;
20. внутренний цикл использует длину конкретной строки массива;
21. итоговый балл каждого спортсмена сохраняется в отдельный одномерный массив;
22. победитель определяется по максимальному итоговому баллу;
23. многомерный массив выводится через `Arrays.deepToString()`;
24. одинаковые по содержимому двумерные массивы корректно сравниваются через `Arrays.deepEquals()`;
25. зубчатый массив содержит строки различной длины;
26. все элементы зубчатого массива обходятся вложенным `for-each`;
27. длина каждой строки зубчатого массива определяется через `.length`;
28. `Arrays.fill()` заполняет массив статусами;
29. элементы `String[]` до присваивания строк имеют значение `null`;
30. вы можете объяснить разницу между ссылкой на массив и копией массива.
