Задание 01. Оформление заказа в маркетплейсе

Вы разрабатываете небольшую часть программы маркетплейса.
Программа должна рассчитать стоимость заказа и вывести в консоль подробный чек.
Все исходные данные задаются в коде; ввод с клавиатуры не требуется.

## 1. Структура программы

В файле `Solution.java` создайте класс «решение» (`Solution`) и главный метод программы (`main`):

```
public static void main(String[] args)
```

Параметр «аргументы командной строки» (`args`) имеет тип `String[]`.
В этом задании он не используется.
Все переменные, вычисления и команды вывода разместите внутри `main`.
Имена переменных должны точно соответствовать указанным английским именам.

## 2. Исходные данные

Объявите следующие переменные сразу с начальными значениями:

* «имя покупателя» (`customerName`) типа «строка» (`String`) со значением `"Alice"`;
* «название товара» (`productName`) типа `String` со значением `"Mechanical Keyboard"`;
* «цена единицы товара» (`itemUnitPrice`) типа «целое число» (`int`) со значением `4800`;
* «количество товаров» (`itemCount`) типа `int` со значением `3`;
* «плата за доставку» (`deliveryFee`) типа `int` со значением `600`;
* «скидка на заказ» (`orderDiscount`) типа `int` со значением `1200`;
* «сервисный сбор» (`serviceFee`) типа `int` со значением `200`.

## 3. Расчёты

Все вычисления выполняйте с переменными.
Не подставляйте готовые результаты в команды вывода или строковые литералы:
изменение цены, количества, доставки, скидки или сбора
должно автоматически менять связанные результаты.

1. Объявите переменную
   «общая стоимость товаров» (`totalItemsCost`) типа `int` **без начального значения**.
2. Отдельной командой присваивания (`=`) запишите в `totalItemsCost` произведение
   цены товара (`itemUnitPrice`) и количества товаров (`itemCount`). Используйте умножение (`*`).
3. Создайте переменную «стоимость заказа до скидки» (`orderCostBeforeDiscount`) типа `int` и
   присвойте ей сумму стоимости товаров (`totalItemsCost`) и платы за доставку (`deliveryFee`).
   Используйте сложение (`+`) и круглые скобки `()` внутри арифметического выражения.
4. Создайте переменную «скидка на один товар» (`discountPerItem`) типа `int`. Разделите
   скидку на заказ (`orderDiscount`) на количество товаров (`itemCount`) оператором деления (`/`).
5. Создайте переменную «итоговая стоимость заказа» (`totalOrderCost`) типа `int`
   и присвойте ей разность стоимости до скидки (`orderCostBeforeDiscount`)
   и скидки на заказ (`orderDiscount`). Используйте вычитание (`-`).
6. Выполните **повторное присваивание** переменной `totalOrderCost`:
   прибавьте к её текущему значению сервисный сбор (`serviceFee`).
   Отдельную переменную для окончательной стоимости создавать не нужно.
7. Создайте переменную «сообщение об итоговой стоимости заказа» (`orderTotalMessage`) типа `String`.
   Конкатенацией (`+`) соедините текст и вычисленное значение `totalOrderCost` типа `int`.
   Сообщение должно совпадать с последней строкой образца ниже, включая пробелы перед суммой.

## 4. Вывод в консоль

Строку с покупателем соберите двумя командами:
подпись и пробелы до значения выведите методом
«вывести без перехода на новую строку» (`System.out.print()`),
затем имя покупателя (`customerName`) методом
«вывести с переходом на новую строку» (`System.out.println()`).

Так же выведите строку с названием товара (`productName`).
Подписи и выравнивание возьмите из образца.
Пробелы для выравнивания записывайте внутри строковых литералов.
Остальные строки соберите конкатенацией строк с переменными и выведите через `System.out.println()`.
Для последней строки используйте уже сформированное сообщение `orderTotalMessage`.

Скомпилируйте и запустите программу.
При заданных исходных данных вывод должен полностью совпасть с образцом:

```text
Покупатель:           Alice
Товар:                Mechanical Keyboard
Цена за единицу:      4800 руб.
Количество:           3
Стоимость товаров:    14400 руб.
Доставка:             600 руб.
Стоимость до скидки:  15000 руб.
Скидка:               1200 руб.
Скидка на один товар: 400 руб.
Сервисный сбор:       200 руб.
Итого к оплате:       14000 руб.
```
