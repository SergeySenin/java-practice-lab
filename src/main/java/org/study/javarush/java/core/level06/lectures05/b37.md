Числа и символы в Java

## 1. Какие бывают числа?

В программировании мы постоянно работаем с числами: от возраста пользователя до числа
звёзд в галактике или копеек на банковском счёте. Но **разные задачи требуют разных видов
чисел**: иногда важно хранить только целые числа, иногда — очень точные дробные числа,
а иногда нужны значения без отрицательных чисел.

### Целые числа: `int` и другие

**Целое число** — это число без дробной части.

В Java чаще всего используют тип `int`, но кроме него есть ещё несколько вариантов, которые
отличаются размером и диапазоном.

* `int` — основной рабочий тип для целых чисел. Он вмещает достаточно большие положительные
  и отрицательные значения, а памяти занимает не так уж много. Например, для подсчёта лайков,
  возраста или количества дней в году почти всегда будет использоваться `int`.
* `long` — используется, если значения могут быть очень большими, например миллиарды
  или триллионы. Пример: хранить сумму всех просмотров YouTube за всю историю.
* `short` — экономичный, но редко используемый тип. Подходит там, где хранится много
  одинаковых небольших значений, например аудиоданные или цветовые компоненты.
* `byte` — тип для ещё меньших значений, особенно в графике и работе с файлами, где важна
  экономия памяти.

### Дробные числа: `double` и `float`

Иногда нужно работать с числами, у которых есть дробная часть. Например, это может быть
температура воздуха, средний балл студента или цена товара с копейками.

* `double` — тип по умолчанию для хранения дробных чисел. Он достаточно точный для большинства
  обычных вычислений. Пример: `3.1415926535`.
* `float` — более лёгкий и менее точный тип. Чаще встречается в задачах компьютерной графики
  или при обработке больших массивов данных, где важна экономия памяти.

### Специальные числовые типы

* `BigInteger` — класс для работы с огромными целыми числами, которые превышают стандартные
  диапазоны. Например, он может использоваться в криптографии или вычислениях в астрономии.
* `BigDecimal` — класс для точных вычислений с дробными числами. Он полезен в финансах,
  расчёте процентов и других задачах, где нужно избежать неточностей, свойственных `double`
  и `float`.

## 2. Диапазоны значений

**Целые типы** могут хранить как положительные, так и отрицательные числа. Это удобно, когда
значения могут быть и выше, и ниже нуля: например, температура, баланс счёта или высота
относительно уровня моря.

Пример:

* `int`: `-10`, `0`, `50`;
* `long`: `0`, `10`, `-1_000_000_000_000_000_000L`.

### Целые типы

| Тип     | Размер  | Диапазон значений                                             |
|---------|---------|---------------------------------------------------------------|
| `byte`  | 1 байт  | от -128<br>до 127                                             |
| `short` | 2 байта | от -32 768<br>до 32 767                                       |
| `int`   | 4 байта | от -2 147 483 648<br>до 2 147 483 647                         |
| `long`  | 8 байт  | от -9 223 372 036 854 775 808<br>до 9 223 372 036 854 775 807 |

| Тип     | Пример использования       |
|---------|----------------------------|
| `byte`  | `-128`, `0`, `127`         |
| `short` | `-1000`, `0`, `32000`      |
| `int`   | `-1000000`, `0`, `2000000` |
| `long`  | `-10_000_000_000L`, `1L`   |

### Дробные типы

| Тип      | Размер  | Пример значений      | Описание                                    |
|----------|---------|----------------------|---------------------------------------------|
| `float`  | 4 байта | `3.14f`, `-0.001f`   | Одинарная точность, около 7 значащих цифр   |
| `double` | 8 байт  | `3.1415`, `-1.7E308` | Двойная точность, около 15–16 значащих цифр |

## 3. Суффиксы для чисел

В некоторых ситуациях нужно явно указать, какой тип вы хотите использовать для числа. Это
делается при помощи **суффиксов**:

* `L` или `l` — для типа `long`, например `10000000000L`;
* `F` или `f` — для типа `float`, например `3.14f`;
* `D` или `d` — для типа `double`. Обычно не нужен, потому что дробные числа без суффикса —
  это `double`.

Если не указать суффикс, то по умолчанию целое число считается значением типа `int`, а дробное
число — значением типа `double`. Например, `42` — это `int`, а `3.14` — это `double`.

Зачем это нужно? Например, чтобы не получить ошибку при присваивании большого числа
переменной типа `long`:

```
long bigNumber = 9000000000L; // Если убрать L, будет ошибка компиляции
```

### Разделитель в виде подчёркивания `_`

Когда числа длинные, легко запутаться в нулях. Для красоты и удобства чтения в Java можно
использовать **подчёркивания** внутри числа.

```
int population = 146_700_000;
long stars = 100_000_000_000L;
```

Использование подчёркиваний для удобства чтения чисел

Это абсолютно легально: компилятор игнорирует подчёркивания, а вам удобно сразу «на глаз»
видеть разряды. Главное — не ставить подчёркивание в начале, в конце, рядом с точкой или
перед суффиксом.

## 4. Символьный тип `char`: что это и зачем?

Тип `char` используется для хранения **одного** символа: буквы, цифры, знака препинания,
пробела или специального символа.

Примеры:

```
char letter = 'A';
char digit = '7';
char symbol = '?';
char cyrillic = 'Ж';
char euro = '€';
char smile = '☺'; // Да, такое тоже можно
```

Важные правила:

* Значение типа `char` записывается в одиночных кавычках: `'A'`, `'7'`, `'#'`.
* Это именно **один** символ. Если написать `'AB'`, компилятор будет возмущаться.
* За каждым символом скрывается свой числовой код Unicode.

### Unicode: символы со всего мира

Java использует стандарт Unicode, что позволяет хранить не только латинские буквы, но
и кириллицу, иероглифы и множество других символов.

#### Интересный факт

Тип `char` — это, по сути, 16-битное значение от 0 до 65 535. Каждому такому значению
соответствует символ или часть символа в кодировке UTF-16. Поэтому простые символы вроде
`'A'`, `'Ж'` или `'€'` помещаются в один `char`, а некоторые эмодзи могут занимать два
`char`.

## 5. Символы и числа: связь через Unicode

Поскольку каждый символ внутри связан с числовым кодом, мы можем преобразовывать `char`
в `int` и обратно.

### Пример: узнать Unicode-код символа

```
public class CharToInt {
    public static void main(String[] args) {
        char ch = 'A';
        int code = ch; // Неявное преобразование char → int

        System.out.println("Код символа '" + ch + "': " + code);
    }
}
```

Результат:

```text
Код символа 'A': 65
```

А теперь наоборот — получим символ по коду:

```
public class IntToChar {
    public static void main(String[] args) {
        int code = 1040;       // Код буквы 'А' в Unicode: кириллица
        char ch = (char) code; // Явное преобразование int → char

        System.out.println("Символ с кодом " + code + ": " + ch);
    }
}
```

Результат:

```text
Символ с кодом 1040: А
```

## 6. Основные примитивные типы Java

| Тип       | Размер        | Диапазон значений                              |
|-----------|---------------|------------------------------------------------|
| `byte`    | 8 бит         | от -128<br>до 127                              |
| `short`   | 16 бит        | от -32 768<br>до 32 767                        |
| `int`     | 32 бита       | от -2 147 483 648<br>до 2 147 483 647          |
| `long`    | 64 бита       | примерно от -9.22 × 10^18<br>до 9.22 × 10^18   |
| `float`   | 32 бита       | примерно от ±1.4 × 10^-45<br>до ±3.4 × 10^38   |
| `double`  | 64 бита       | примерно от ±4.9 × 10^-324<br>до ±1.7 × 10^308 |
| `char`    | 16 бит        | от 0<br>до 65 535                              |
| `boolean` | не фиксирован | `true`,<br>`false`                             |

| Тип       | Примечание                        |
|-----------|-----------------------------------|
| `byte`    | Очень редко используется          |
| `short`   | Для экономии памяти               |
| `int`     | Основной тип для целых чисел      |
| `long`    | Для очень больших целых чисел     |
| `float`   | Дробные числа, одинарная точность |
| `double`  | Дробные числа, двойная точность   |
| `char`    | Один символ UTF-16                |
| `boolean` | Логическое значение               |
