  `update(String news)`.
* Класс `Person` должен иметь конструктор, принимающий имя подписчика и сохраняющий его для
  последующего использования.
* В методе `update` класса `Person` должно выводиться сообщение в формате
  `"<имя> получил новость: <news>"`.
* В основной части программы необходимо создать объект `NewsPublisher`, двух `Person` с разными
  именами, подписать их на издателя и вызвать `notifySubscribers` с новостью, чтобы на экране
  появились корректные сообщения для каждого подписчика.
