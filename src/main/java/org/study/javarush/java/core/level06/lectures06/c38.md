Введение в дробные числа и тип `double`

## 1. Дробные числа

Допустим, вы решили написать простейший калькулятор. Или любую другую программу, где нужны
вычисления: от банального подсчёта денег до сложной физики. Далеко не всё в реальной жизни —
целое число, и с этим ничего не поделаешь.

Так что давайте вооружимся новым типом данных!

В программировании дробные числа ещё называют **вещественными**, или
**числами с плавающей точкой** — floating-point. В Java, как и в большинстве языков, они
нужны для хранения не только целых, но и дробных значений: например `3.14`, `-28.57`,
`2.718281828`.

Вещественные числа (хранят числа с плавающей точкой) бывают двух основных типов:

| Тип      | Диапазон значений, приблизительно  | Точность                  | Размер  |
|----------|------------------------------------|---------------------------|---------|
| `float`  | от ±1.4 × 10^-45 до ±3.4 × 10^38   | около 7 значащих цифр     | 4 байта |
| `double` | от ±4.9 × 10^-324 до ±1.7 × 10^308 | около 15–16 значащих цифр | 8 байт  |

### Тип `float`

Тип `float` получил название от **floating-point number** — число с плавающей точкой.
Вещественные числа — это математическое понятие, а у компьютера есть ограничения. Поэтому
дробные числа в Java корректнее называть числами с плавающей точкой.

Тип `float` обычно хранит около 7 значащих цифр и занимает 4 байта в памяти. Этого мало
для точных вычислений, поэтому в большинстве обычных задач используют числа двойной точности —
тип `double`.

### Тип `double`

Тип `double` получил своё название от **double precision**, то есть «двойная точность».
Он занимает в памяти 8 байт, в 2 раза больше, чем `float`, и может хранить около
15–16 значащих цифр. Например: `0.123456789012345`. Этого достаточно для большинства
вычислений с дробными числами, поэтому `double` является основным типом для хранения дробных
чисел в Java.

В нынешней лекции основной акцент будет на типе `double`: он по умолчанию рекомендуется
для всех обычных дробных чисел. Но дальше мы рассмотрим и тип `float`.

## 2. Объявление и инициализация переменных типа `double`

Всё как с `int`, только теперь используем `double`.

```
// Объявляем переменную и присваиваем ей значение числа пи
double pi = 3.1415926;

// Можно объявить и без инициализации
double averageSalary;
averageSalary = 91234.56;

// Можно вычислять
double pizzaPieces = 8;
double friends = 3;
double piecesPerFriend = pizzaPieces / friends; // 2.666... а не 2
```

### Особенности синтаксиса

* В качестве десятичного разделителя используется точка: `3.14`. Если использовать запятую,
  будет ошибка компиляции.
* Если написать `double d = 3;`, ошибки не будет: целое число автоматически преобразуется
  в `double` без потери значения.

## 3. Ввод и вывод вещественных чисел с помощью `Scanner`

Сначала попробуем вывести дробное число:

```
double amount = 42.75;
System.out.println(amount); // Выведет: 42.75
```

Всё хорошо. А если добавить текст:

```
System.out.println("На вашем счету: " + amount + " евро."); // На вашем счету: 42.75 евро.
```

### Ввод с клавиатуры

Для ввода `double` нужно использовать специальный метод класса `Scanner` — `console.nextDouble()`.

```
Scanner console = new Scanner(System.in);

System.out.println("Введите температуру за окном:");
double temperature = console.nextDouble(); // Сразу вводим double

System.out.println("На улице сейчас: " + temperature + " градусов.");
```

## 4. Тип `double` в действии: арифметика

Все привычные операции — `+`, `-`, `*`, `/` — работают так же, как и для `int`:

```
double distance = 100.5;
double time = 2.0;
double speed = distance / time; // 50.25

System.out.println("Средняя скорость: " + speed); // Средняя скорость: 50.25
```

Вот и вся арифметика. Главное отличие: результат деления будет дробным, если хотя бы один
из операндов имеет тип `double`.

### Сравним с `int`

```
int a = 5, b = 2;
System.out.println(a / b); // 2, остаток отбрасывается

double aa = 5, bb = 2;
System.out.println(aa / bb); // 2.5
```

## 5. Типичные ошибки и странности при работе с `double`

### Ошибка преобразования ввода

Ситуация классическая: пользователь вводит `3,14`, а программа ждёт `3.14`. В Java метод
`Scanner.nextDouble()` ориентируется на текущую **локаль**: в русской или немецкой локали
запятая может быть допустима, а в английской обычно нужна точка. При необходимости настройте
локаль для `Scanner` или считывайте строку и разбирайте её вручную.

```
// Это вызовет проблему в Locale.US, если введено "3,14"
double value = console.nextDouble();
```

### Ошибка неточности чисел в компьютере

Вот здесь у новичков обычно начинается лёгкое недоумение:

```
double x = 0.1 + 0.2;
System.out.println(x); // Хм... 0.30000000000000004
```

Поздравляю, вы столкнулись с «магией» представления дробных чисел внутри компьютера. Дело
в том, что многие десятичные дроби невозможно точно представить в двоичной системе. Это
обычно некритично для большинства приложений, но есть нюансы в финансах и точных науках.

## 6. Важно: `double` и `int` — автоматическое и явное преобразование

Бывает, что вы складываете целое и дробное число или присваиваете значение типа `int`
переменной типа `double`. Ошибок не будет:

```
int i = 2;
double d = i; // Всё ок
System.out.println(d); // 2.0

double dd = 3.7;
int ii = (int) dd; // Нужно явно привести double к int
System.out.println(ii); // 3, дробная часть отбросилась
```

Часто это вызывает неожиданность: почему после приведения дробная часть исчезла? Просто
потому, что тип `int` не умеет хранить дроби. Всё, что после точки, исчезает.

Подробнее про преобразование `double` в `int` и оператор `(int)` поговорим в следующей лекции.

## 7. Форматированный вывод: красиво выводим `double`

Часто значение `double` нужно вывести в определённом формате. Например, с двумя знаками после
точки:

```
double temp = 23.56789;
System.out.println(temp); // 23.56789

// 2 знака после точки
System.out.println(String.format("%.2f", temp)); // 23.57

// 1 знак после точки
System.out.println(String.format("%.1f", temp)); // 23.6
```

| Формат   | Результат | Описание                      |
|----------|-----------|-------------------------------|
| `"%.2f"` | `23.57`   | Число с 2 знаками после точки |
| `"%.1f"` | `23.6`    | Число с 1 знаком после точки  |

## 8. Типичные ошибки при работе с `float` и `double`

### Неявное преобразование `double` в `float`

```
float f = 1.23; // Ошибка
```

Компилятор будет недоволен: вы пытаетесь положить `double` в `float`, а это может привести
к потере точности. Всегда добавляйте суффикс `f` или `F`.

Правильно:

```
float f = 1.23f;
```

### Забыли, что деление двух `int` даёт `int`-результат

```
int a = 7, b = 2;
double result = a / b; // 3.0, а не 3.5
```

Чтобы получить дробную часть, явно преобразуйте хотя бы один операнд:

```
double result = (double) a / b; // 3.5
```

### Сравнение дробных чисел

Не сравнивайте дробные числа на равенство с помощью `==`, если результат получен вычислениями.
Лучше используйте сравнение с небольшим допуском — `epsilon`.

```
double x = 0.1 + 0.2;
double y = 0.3;

double epsilon = 0.000001;

if (Math.abs(x - y) < epsilon) {
    System.out.println("Числа практически равны");
}
```

### Потеря точности у `float`

Не храните большие числа или очень точные значения в `float`: они могут потерять важные цифры.
Для обычных дробных вычислений чаще используйте `double`.
